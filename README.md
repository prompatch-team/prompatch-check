# prompatch-check

체험단 블로거가 원고를 내기 전에, 광고주 가이드의 조건을 지켰는지 **조건별 숫자와 원문 위치**로 보여 주는 서비스예요.
글을 대신 쓰지 않고, 빠진 것만 정확히 보여 줘요.

PRE-SOMA 부산 PromPatch 팀 저장소예요. 제품 이슈와 기획 문서는 [prompatch-common](https://github.com/prompatch-team/prompatch-common)에 있어요.

## 구조

| 폴더 | 영역 | 담당 | 하는 일 |
| --- | --- | --- | --- |
| `ai/` | AI | 훈 | 가이드 원문 → 조건 목록 |
| `be/` | BE | 감자 | 조건 + 원고 → 점검 결과, 배포 |
| `fe/` | FE | 리릭 | 붙여 넣기 화면, 결과 화면 |
| `criteria/` | 기준 | 카티 | 정답지(손 누락표)와 비교 기록 |
| `contracts/` | 연결 | owner | 영역 사이에 주고받는 JSON 형식과 예시 |
| `samples/` | 공용 | 전원 | 지어낸 예시 가이드와 원고 |
| `tools/` | 공용 | 전원 | 커밋 전 대조 (실제 글·주소·키가 섞여 들어가지 않게) |

```
가이드 ──▶ [ai] ──연결 ① 조건 목록──▶ [be] ──연결 ② 점검 결과──▶ [fe]
                  owner 훈                       owner 리릭
원고·사진 수 ──────────────────────────▶ [be] ◀──연결 ② 점검 요청── [fe]
                          [criteria] 정답지로 세 영역을 맞춰 봐요
```

## 각자 개발하는 법

1. 내 영역 폴더에서만 작업해요. 다른 영역 폴더는 고치지 않아요.
2. 앞 영역이 아직 없어도 `contracts/*.example.json` 예시 파일로 개발해요. 서로 기다리지 않아요.
3. 내가 내보내는 JSON은 `python contracts/validate.py <종류> <파일>`로 형식을 확인해요.
4. 영역 안의 방법(언어, 라이브러리, 프롬프트, 화면 구성)은 각자 정해요. 정한 건 내 폴더 README에 적어요.

## 합치는 법

- **연결 ①** 조건 목록: owner 훈이 감자와 맞춰 AI 결과를 서버에 이어요.
- **연결 ②** 점검 요청과 결과: owner 리릭이 감자와 맞춰 화면을 실제 서버에 이어요.
- **전체 흐름과 배포**: owner 감자가 처음부터 끝까지 이어요.
- 형식을 바꾸려면 owner가 정하고, `contracts/`의 스키마·예시와 `version`을 함께 고쳐 PR로 올려요.

## 처음 시작하기

```bash
git clone https://github.com/prompatch-team/prompatch-check.git
cd prompatch-check
git switch -c 닉네임-작업          # 예: hun-extract
cp .env.example .env               # AI 키가 필요한 사람만. .env는 올라가지 않아요
cd ai                               # 내 영역 폴더로
claude                              # 이슈의 "다 된 기준"을 붙여 넣고 시작
```

끝나면 바뀐 내용을 읽어 본 뒤 "커밋하고 PR 만들어 줘". PR 본문에 `Closes #이슈번호`를 쓰고, 다른 팀원 한 명이 보고 Merge해요.

## 지킬 것

- **글은 대신 쓰지 않아요.** 빠진 것과 위치까지만 보여 줘요.
- **셀 수 있는 건 코드로.** AI는 조건 뽑기와 셀 수 없는 조건만 맡아요.
- **모르면 단정하지 않아요.** 판단 보류(`hold`)로 남겨요.
- **실제 가이드와 원고는 올리지 않아요.** `samples/`에는 지어낸 예시만 둬요. 실제 자료는 팀 드라이브에. 커밋 전에 자동으로 걸러지게 한 번만 설치해요: `python tools/leak_check.py --install`
- **공개 저장소예요.** API 키, 토큰, 웹훅 주소, 개인 정보, 블로그 주소는 넣지 않아요.
- 커밋 이메일은 GitHub의 noreply 주소로 해요.
