# criteria: 정답지 (카티)

손으로 찾은 정답지예요. 세 영역의 결과를 이 표와 맞춰 봐요.

- `answer-key-template.md`: 정답지 틀
- `sample-answer-key.md`: `samples/`의 예시 가이드·원고 정답지
- `results/`: 날짜별 비교 기록 (예: `results/2026-12-01.md`)

## 실제 원고의 정답지

실제 가이드·원고의 손 누락표는 **팀 드라이브에만** 둬요. 이 저장소에는 원문 없이 조건 이름과 숫자만 옮겨요.

## 비교 기록에 남길 것

- 영역별로 정답과 다른 곳: 잘못 뽑은 조건(오탐), 놓친 조건(미탐), 숫자가 다른 곳
- 왜 다른지 근거. 고치는 방법은 각 영역이 정해요
