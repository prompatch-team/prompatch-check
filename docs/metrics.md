# 지표 기록 (전/후)

작업에서 나온 전/후 숫자를 모아요. 표는 셋이에요: **성능 개선**, **기준 변경 기록**, **참고**. 새 숫자가 나오면 맞는 표에 한 줄씩 더해요.

- 실제 가이드·글의 내용(가게·제품 이름, 원문 문장)은 적지 않아요. 숫자와 조건 종류만 적어요. 실제 자료와 정답지는 저장소 밖에 있어요.
- 실제 가이드는 레뷰 3개(G1~G3), 강남맛집 3개(K1~K3)예요. 실제 글은 이름 대신 개수로만 적어요.
- "잰 방법"에는 몇 번 불렀는지(호출 수), 몇 개로 쟀는지(사례 수)를 적어요. 같은 응답을 코드만 바꿔 다시 채점한 것은 "다시 채점"이라고 적어요.
- 정답지를 고쳐서 바뀐 숫자는 성능 개선이 아니라 "기준 변경 기록"에 적어요.
- **비교 주의**: 전과 후를 잰 방법(호출 수, 사례, 기준)이 달라서 그대로 비교하기 어려운 줄이에요.

## 점검 한 번의 비용

토큰 수로 계산했어요. 가격은 Claude Haiku 5.5(프롬프트 10만 토큰까지)의 1M 토큰당 입력 $0.10, 출력 $0.50, 캐시 읽기 $0.01, 캐시 쓰기(5분) $0.125예요.
가격 확인: 2026-11-28, https://platform.claude.com/docs/en/about-claude/pricing (프롬프트가 10만 토큰을 넘으면 더 비싸요. 우리 요청은 그보다 훨씬 짧아요).
원은 **1달러 = 1,400원으로 어림**했어요 (환율은 바뀌어요. 서버 설정 `PROMPATCH_KRW_PER_USD`).

| 무엇 | 토큰 (한 번 평균) | 달러 | 원 | 잰 방법 |
| --- | --- | --- | --- | --- |
| 1단계: 코드가 고정 칸 읽기 + 점검 | AI 없음 | 0 | 0원 | - |
| 2단계: 가이드의 나머지 조건 뽑기 (생각 끔, effort medium) | 입력 1,490, 출력 1,057, 캐시 읽기 3,862, 캐시 쓰기 351 | $0.00076 | **약 1.1원** | 6개 × 2번 = 12번 합계 $0.00912 |
| 셀 수 없는 조건 AI 판단 (설정에서 켰을 때만) | 입력 1,230, 출력 114, 캐시 읽기 654 | $0.00019 | 약 0.3원 | 비교 실험의 판단 6번 |
| **점검 한 번** (AI 판단 끔 / 켬) | | $0.00076 / $0.00095 | **약 1.1원 / 1.3원** | 위 두 줄의 합 |

- 원고만 고쳐 다시 점검하면 조건을 다시 뽑지 않아서 AI 비용이 0원이에요 (판단을 켰고 원고가 바뀌었으면 판단 한 번).
- 서버 기록에도 AI를 부를 때마다 토큰 수와 그 비용(`cost_krw`, 원)이 숫자로 남아요.

## 서버 기록으로 재는 것 (2026-11-27부터)

- `timing`: 화면이 잰 시간. `first_ms` = 점검하기를 누르고 첫 결과(코드가 읽은 결과)가 보일 때까지, `full_ms` = 가이드의 나머지까지 이어 붙일 때까지(못 읽었으면 비어 있음), `ai` = done 또는 failed. 숫자만 받고 숫자만 남겨요.
- `rules`: 1단계 코드 읽기 시간(`rules_ms`)과 조건 수. `extract`, `judge`: AI 시간(`ai_ms`), 토큰 수, 비용(`cost_krw`). `check`: 점검 시간(`check_ms`).
- 실제 서비스에서 모인 숫자가 생기면 맞는 표에 한 줄씩 더해요.
