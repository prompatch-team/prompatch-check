# fe: 붙여 넣고 조건별로 보기 (리릭)

블로거가 가이드와 원고를 붙여 넣으면, 빠진 조건과 그 자리를 원고 위에 표시해 보여 줘요. 연결 ② owner예요.

- **보내는 것**: 점검 요청 (`contracts/check-request.example.json`, 0.4)
- **받는 것**: 점검 결과 (`contracts/check-result.example.json`, 0.4)
- 지금 화면은 리릭님이 이어서 만드실 **출발점**이에요. 디자인과 화면 구조는 리릭님이 정하시면 그대로 따를게요.

## 실행

1. 서버 없이: 크롬에서 `fe/index.html`을 열면 예시 모드예요 (지어낸 예시 4개로 화면 전체가 돌아요)
2. 서버와 함께: `python -m uvicorn be.server:app --port 8000` → `http://127.0.0.1:8000` (키 없이 돌리려면 `.env`에 `PROMPATCH_AI_MODE=recorded`)
3. 시험: 저장소 맨 위에서 `python -m unittest` (모든 영역 테스트를 한 번에 돌려요. 크롬이 있으면 화면 자체 시험까지, 주소 끝에 `#selftest`를 붙여 열면 눈으로도 볼 수 있어요)

## 화면 흐름

1. **처음 화면**: "가이드", "원고" 두 칸과 "점검하기" 하나. 원고를 서식째 붙여 넣으면 사진·동영상·지도 수를 읽어요 (서식은 화면에 넣지 않고 글자만 보여 줘요). 제목 칸은 선택이에요.
2. **점검**: 먼저 코드가 고정 칸에서 읽은 조건으로 점검해 보여 주고, 가이드의 나머지(AI 몫)가 도착하면 이어 붙여요.
3. **결과(교정지)**: 맨 위 "고칠 곳 N개". 원고 위에 고칠 곳을 빨간 물결과 번호로, 옆 여백에 짧은 메모를 달아요. 직접 확인할 것, 지킨 것, 원고 밖 조건, 도움이 될 팁(펼쳤을 때만 원고에 연한 색), 대가성 문구 예시, 네이버 키워드 링크는 아래에 접어 둬요.
4. **필요할 때만 묻는 칸**: 제목을 모를 때, 글만 붙여 넣어 사진 수가 없을 때, 기준 숫자를 확인하지 못했을 때 등.
5. **설정**(접힘): 사진 설명을 글자 수에 넣기, 도움이 될 팁 보기, 셀 수 없는 조건도 AI로 살펴보기(기본 끔).

## 지키는 것

- 붙여 넣은 글은 글자로만 화면에 써요. 서식(HTML)으로 넣지 않고, 사진을 불러오지 않아요.
- 요청은 `api.js` 한 곳에서 우리 서버의 `/api/` 아래로만 보내요. 브라우저 설정(CSP)으로도 막아 뒀어요. 주소(URL) 입력칸이 없어요.
- 결과 문구(`note`)는 서버가 준 그대로 보여 줘요. 글을 대신 쓰거나 고쳐 주는 기능은 없어요. 예외는 대가성 문구 예시(고정 문구)와 도움이 될 팁의 짧은 틀이에요.
- "판정이 틀렸어요"는 동의한 경우에만 조건 이름과 판정만 보내요.

## 부족한 곳 (리릭님이 이어서 정할 것)

- 디자인: 시안 A(정돈된 교정지)로 정했지만 다듬기 전이에요. 색·글자 크기·여백 값은 `style.css`의 `:root`에만 있어요.
- 사진 수: 실제 글로 센 값은 저장소 밖에서 확인했고, 저장소 안에는 에디터에서 복사한 지어낸 글(`samples/editor/`)로만 시험이 있어요.
- 휴대폰 화면은 캡처로만 봤어요. PC 크롬 기준이에요.
- 개인정보 안내(`privacy.html`)는 초안이에요. 문의처와 서버 위치가 [미정]이에요.
- `app.js`가 한 파일에 흐름이 다 들어 있어서 커요(약 700줄).
