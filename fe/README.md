# fe: 붙여 넣고 조건별로 보기 (리릭)

블로거가 가이드와 원고를 붙여 넣고 사진 수를 입력하면, 조건마다 지킴·빠짐·판단 보류를 한 줄씩 보여 줘요. 연결 ② owner예요.

- **보내는 것**: 점검 요청 (`contracts/check-request.example.json`)
- **받는 것**: 점검 결과 (`contracts/check-result.example.json`)
- 서버 자리는 처음에 `check-result.example.json`으로 대신해요. 연결 ②가 되면 실제 API로 바꿔요.

## 화면 기준

- 조건마다 상태와 숫자를 한 줄로 (예: 빠짐, "전포동 카페" 3 / 5회)
- 빠진 조건을 누르면 원고 안 위치(`draft_spans`)가 바로 보이게
- 블로거가 글을 쓰는 PC 화면 기준으로 먼저
- 결과에 "고쳐 드릴까요" 같은 대신 쓰기 기능은 넣지 않아요
