# 글쓰기 화면 복사 시험 자료 (2026-11-27)

`editor-test.html`은 카티가 네이버 블로그 글쓰기 화면에서 직접 복사한 HTML이에요. 지어낸 글이고 실제 사례가 아니에요.

## 저장소에 넣기 전에 바꾼 것

- 사진 주소 7개는 `https://example.com/photo-1.png` ~ `photo-7.png`로 바꿨어요(원래 blogfiles.pstatic.net).
- 그 밖의 그림 주소 4개도 example로 바꿨어요: 동영상 썸네일(`img`와 `style` 배경), 지도 그림, 스티커, 링크 카드 썸네일.
- 사진의 `alt`(스크린샷 파일 이름, 찍은 날짜·시각)는 `photo.png`로 바꿨어요.
- 지도 블록의 장소 이름과 주소는 실제 가게라서 지어낸 값(`시험맛집 예시점`, `서울특별시 예시구 예시로 1`)으로 바꿨어요.
- 블로그 아이디, 동영상 키 같은 계정 값은 원래 없었어요. `id="SE-…"`는 편집기가 부품마다 무작위로 붙이는 값이라 두었어요.
- `fe/test_fe.py`의 `test_sample_has_no_account_addresses`가 pstatic 주소와 스크린샷 이름이 다시 들어오지 않는지 봐요.
